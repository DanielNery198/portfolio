# Portfólio Pessoal — Daniel Nery

## Sobre o projeto

Este projeto consiste em uma página pessoal desenvolvida para apresentar quem sou, minha história, minha visão, minhas conquistas, as características que me definem e meus trabalhos acadêmicos concluídos.

A página foi criada com o intuito de reunir essas informações em um único espaço, permitindo que outras pessoas conheçam melhor minha trajetória, meus projetos e um pouco da minha identidade.

## Como a página foi desenvolvida

O desenvolvimento da página começou a partir de um prompt já pronto, disponibilizado pelo meu instrutor do curso de Informática para Internet. Esse prompt serviu como base e orientação para a criação do projeto, que foi desenvolvido com o auxílio de inteligência artificial (IA).

A partir das instruções fornecidas, a página foi construída e organizada para apresentar minhas informações de maneira visual, interativa e acessível.

## Tecnologias utilizadas

Para desenvolver esta página, foram utilizadas as seguintes tecnologias:

- **HTML:** estruturação do conteúdo.
- **CSS:** estilização, organização visual e responsividade.
- **JavaScript:** implementação de interações e funcionalidades.

## Funcionalidades da página

A página conta com diferentes recursos para proporcionar uma experiência de navegação mais dinâmica e agradável:

- Alternância entre os temas claro e escuro.
- Menu de navegação fixo.
- Barra de progresso da leitura.
- Animações durante a rolagem da página.
- Efeito de movimento na imagem de apresentação.
- Carrossel interativo para exibição dos trabalhos.
- Ampliação de imagens ao clicar nelas.
- Seção de manifesto expansível.
- Easter egg com gráfico animado, ativado pelo atalho `Ctrl + D`.
- Layout responsivo, adaptado a diferentes tamanhos de tela.
- Recursos de acessibilidade e suporte à navegação pelo teclado.

## Estrutura e desenvolvimento

O conteúdo foi organizado em seções para facilitar a navegação e tornar a apresentação das informações mais clara.

Também foi criada uma identidade visual própria, com elementos interativos, animações e uma organização que valoriza o conteúdo apresentado.

O projeto permitiu explorar recursos de desenvolvimento web e compreender como a inteligência artificial pode auxiliar na criação de páginas, seguindo orientações e instruções previamente estabelecidas.
